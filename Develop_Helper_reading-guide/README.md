# Develop Helper：中文阅读指南

整理日期：2026-09-12。适用对象：本文件夹中的 SDD V7_2。本文档组用于理解框架，不引入新的开发阶段、审批要求或角色。

这套框架把开发组织成一条可追踪的链：**确认用户结果 → 确认实现方案 → 确认必要界面 → 拆出可验收任务 → 实现与独立测试 → 用户检查关键成果 → 交付可运行项目和功能说明。**

它有三种不同性质的内容：给智能体遵循的工作规则、辅助检查和创建项目的脚本、供业务项目使用的 PyCore 后端代码。理解执行流程时，先看前两类。

## 使用者主要负责什么

你主要确定产品目标、范围、验收结果和重要体验取舍，并查看实际成果。智能体负责提出实现方案、拆任务、编码、验证和记录。确认应针对具体内容；已有明确确认与授权可以沿用，无须每个章节重新确认。

通常会遇到：基础信息缺项、PRD 整体确认、技术方案整体确认、必要界面确认、推进模式选择、前端 Mock 与配置确认、逐步模式的每任务确认，以及实际缺失的权限或重大决策。

- “原规范要求”来自核心文档；“脚本行为”来自当前源码；“示例”均为讲解假设，不代表已经创建对应项目。
- 本次保留原文位置和核心规则，补充人类可读导航与说明。原文不足集中记录在 07。
