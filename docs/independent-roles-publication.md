## 收录与排除

保持 `fusion-runtime/workflows/requirements`、`Solution Designer`、`UI` 的既有相对布局与方法软链，源码入口见[角色目录](../fusion-runtime/README.md)。方案与 UI 运行时显式复用 requirements 基础，不依赖旧 helper 或协作宿主在线。

不收录本机 `config/local.json`、配置备份、业务成果、个人运行记录、验证日志、退役程序 Workflow、LangGraph 实验、Agent 操作手册或建设期派发计划。工具规格与正式测试保留用于核对契约；涉及未发布建设文件的链接改为明确的文字引用。

## 定向适配

角色运行 Python 代码保持开发工作区原字节。发布 README 和使用说明面向新安装，UI 主文与文件约定校准旧可用性描述，协议文档保留原字段与保护规则。真实案例的本机路径替换为通用占位路径；来源 JSON 排除个人实例安装记录，保留需要强制核对的模块、方法和文档摘要。

现有上游快照与开发机只有两份文件内容不同：`project-registry.json`、`learning/technical-terms/index.md`。它们在固定提交中是空白项目／学习状态，因此不发布个人工作树变化。逐文件对照后，发布锁采用该准确快照；对应摘要在记录中明确更新。原锁与新锁、两项差异摘要及每份发布文件见[发布清单](../upstream/independent-roles-publication.json)。

需求来源复制测试针对这一经过审查的锁适配更新断言，其余字节复制和锁与实际快照一致性检查保留。没有放宽运行时来源、目录、版本、用途确认或 UI 导入校验。
