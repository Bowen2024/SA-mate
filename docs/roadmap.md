# 近期建设与发布路线

更新日期：2026-11-03。当前围绕需求、方案、UI 的 Agent＋MCP 独立使用推进，具体实施按各项范围和实际验证结果记录。本页列出方向，不将待建设能力写成已交付功能。

| 顺序 | 建设内容 | 完成依据 |
| --- | --- | --- |
| 1 | 校准仓库定位、当前架构、状态及阅读入口 | 首页、当前说明和历史标识一致；本次为文档发布 |
| 2（本批已发布） | 三个角色、共享基础、必要模板和测试 | 明确文件清单；不含本机配置、业务资料、备份或运行状态；相对链接与来源可核对 |
| 3（本批验证） | 安装和离线验证说明 | 干净克隆可恢复方法入口、配置与依赖，执行准确检查；不沿用未经核对的本机锁定摘要 |
| 4 | 按项目使用用户明确指定的完整目录 | 需求、方案、UI 共享目录与身份绑定；保存凭据、历史、UI 事务和导入授权保持隔离；兼容旧模式 |
| 5 | 补齐实际客户端与业务验证 | 分角色、分客户端记录读取、保存、修改、冲突、历史与新会话恢复，不以隔离夹具替代真实链 |
| 6 | 补齐独立环境的确认及成果衔接 | 明确受信确认入口、准确版本与用途核验，再验证需要确认的工程保存流程 |
| 按需 | 整理共享基础和代码命名 | 先明确影响，再处理导入、相对链接、配置、来源摘要与回归；不与当前文档发布混做 |

目录改造首版不包含非空文件夹自动接管、项目自动搬迁、全局项目注册中心或远端同步。业务项目继续原地使用，升级不改写已有业务正文或历史。

## 当前阶段不建设

- LangGraph 或其他通用工作流引擎。
- 独立 Agent Runner、常驻 Host、默认后台推进循环。
- 以 Buzz 为前提的协作入口或生产接线。
- 统一 Main 自动路由、多角色自动调度与完整工程执行链。

以后出现明确需要时重新评估具体问题、收益和接入成本；现阶段不预设这些组件必然回归。已有研究资料保留为[历史设计](../fusion-design/README.md)。
