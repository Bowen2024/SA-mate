# 融合设计发布范围

日期：2026-10-20。本批按用户要求发布与 SA-mate 融合架构、能力、角色、成果及执行边界直接相关的设计文档，并更新首页第 2 板块。

## 收录内容

保留 `fusion-design/` 的原主文文件名，便于沿既有编号阅读：00 总体框架，01 项目与资料，02 需求，03 方案，05 成果与确认交接，06 角色与运行时。

同时收录 Main 用户入口角色设计、05 与 06 的必要伴随依据、单元设计模板，共 10 份本地来源文档。发布版另建 `fusion-design/README.md` 作为阅读导航。

两份伴随依据直接承接主文中的来源、确认及验收范围，保留相应事实和限制。它们不因含历史记录而变成一次新的验收。

**不收录**：`DOCUMENTATION_CLEANUP_PLAN/`、同名整理计划文件、`agent-rule/`、原 README 中的建设管理与本地恢复索引。也不带入业务项目、凭据、运行状态、融合工具源码、Runtime 实现或 Buzz 源码。

## 发布副本做了什么处理

- 为每份来源文档增加发布说明，提示按各段原日期、任务与验收范围阅读。
- 保留原文的业务职责、设计决定、建议状态、阶段条件、计数与限制，不借发布修改它们。
- 本机绝对路径替换为下表的命名占位符，避免读者使用某台机器的目录。占位符用于解释原记录，不是已经配置的环境变量。
- 能在当前仓库读取的 Markdown 链接保持可访问；尚未发布的实现与证据转为明确的文字引用。
- 被排除的建设管理材料只标记为不收录，不建立空文件或误导性的跳转入口。
- 代码块和行内代码中的历史示例保留其语境，仅做本机路径替换；不会因为示例出现某个命令就执行它。

| 占位符 | 含义 |
| --- | --- |
| `${WORKSPACE_ROOT}` | 原融合工作区根 |
| `${PROJECTS_ROOT}` | 各自独立的业务项目所在父目录 |
| `${BUZZ_ROOT}` | 外部 Buzz 源码位置 |
| `${AGENT_HOME}` | 原 Agent 的本机启动目录 |
| `${USER_HOME}` | 原用户本机目录 |
| `${TEMP_ROOT}` | 临时证据所在位置 |

本机临时证据和外部实现没有因替换路径而被上传；保留历史引用不表示在 GitHub 上已经可以核验其内容。

## 状态与来源

发布文档来自用户提供的本地工作树，包含尚未进入父仓 HEAD 或 index 的文档成果。仅用一个父仓提交号不能代表本批来源，因此按文件记录本地原文和发布副本的 SHA-256 与字节数。

逐文件来源、编辑类型和未随本批发布的引用见 [融合设计来源清单](../upstream/fusion-design-source.json)。清单只用于追溯本批文档，不是工作流状态库、验收报告或新的设计权威。

资料中的实现与验收记录按各自原日期、入口及任务范围理解。本批不重签这些结论，不补记生产迁移或真实 Runner 已接通，也不以文档发布替代业务验收。
